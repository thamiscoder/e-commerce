Projeto de e-commerce estático chamado **Market Mingle**, desenvolvido para praticar construção de páginas comerciais com HTML5, CSS3 e JavaScript.

## Sobre o projeto

O `e-commerce` é uma página web de loja virtual fictícia voltada para exposição de produtos.  
A interface apresenta uma área inicial com marcas, imagens de produtos, navegação simples e seção de contato.

O projeto também possui um carrossel automático feito com JavaScript, trocando imagens em intervalo definido para deixar a vitrine mais dinâmica.

## Funcionalidades

- Página inicial de loja virtual fictícia;
- Identidade visual com o nome **Market Mingle**;
- Navegação com seções de produtos, notas e contato;
- Exibição de marcas como Samsung, Apple, Xiaomi e Sony;
- Galeria de produtos com imagens;
- Carrossel automático de imagens;
- Layout organizado com CSS próprio;
- Uso de Media Queries para adaptação visual.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Media Queries.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/thamiscoder/e-commerce.git
```

2. Acesse a pasta do projeto:

```bash
cd e-commerce
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências, pois o projeto é composto apenas por arquivos estáticos.
